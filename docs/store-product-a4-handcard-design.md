# 店铺商品 A4 产品手卡设计

## 目的与范围

每个店铺商品都可以从“商品与售后”列表直接打开一份A4纵向产品介绍手卡。手卡用于店员、主播、品牌方和现场活动的商品说明，可在浏览器中预览，并通过浏览器打印功能直接打印或保存为PDF。功能提供普通版和整页左右镜像版，两种版本共用同一份商品内容，不维护重复数据。

## 数据真实性边界

系统自动使用已经登记的商品名称、品牌、类别、价格、SPU、SKU、库存和商品图片。商品介绍、卖点、成分或特点、使用方法、适用对象、注意事项、主播话术、常见问题、试验结果和专利证书等内容，只有用户明确填写后才显示。任何缺失字段都显示“未登记／请补充”，系统不会根据商品名或图片推测功效、成分、试验结果或专利。

## 手卡数据契约

| 字段 | 类型与限制 | 用途 |
|---|---|---|
| `productId` | 正整数，唯一 | 与店铺商品一对一关联 |
| `subtitle` | 255字符以内 | 产品副标题、规格或容量 |
| `shortDescription` | 800字符以内 | 页面1简短说明 |
| `sellingPoints` | 最多6项，每项160字符 | 核心卖点 |
| `ingredients` | 最多8项；名称、主要作用、顾客利益各160字符 | 页面2三列表格；也可用于非化妆品的特点／功能说明 |
| `usage` | 1,000字符以内 | 使用方法 |
| `targetAudience` | 800字符以内 | 适用对象 |
| `precautions` | 1,200字符以内 | 注意事项 |
| `liveScript` | 1,200字符以内 | 店员／主播说明话术 |
| `faqs` | 最多4项；问题240字符、回答300字符 | 常见问题 |
| `evidenceItems` | 最多4项；标题、说明、数值、既有商品图片ID | 试验、专利、证书或依据；仅引用本商品已登记图片 |
| `theme` | `aqua_light` 或 `navy` | 参考PDF的浅色／深色风格 |
| `revision` | 正整数 | 保存版本号，便于审计 |

## A4页面结构

| 页面 | 主要内容 | 缺失内容处理 |
|---|---|---|
| 第1页 商品概要 | 品牌、商品名、副标题、主图、简短说明、价格、SPU／SKU、卖点 | 使用现有商品基础资料；介绍与卖点未登记时明确提示 |
| 第2页 成分／特点 | 三列表格：成分或特点、主要作用、顾客利益；使用方法与适用对象 | 未登记时不生成虚假表格，显示需要补充 |
| 第3页 讲解与依据 | 主播话术、FAQ、注意事项、试验／专利／证书等依据图片 | 没有依据时显示“依据资料未登记”，不声称存在试验或专利 |

## 普通版与镜像版

普通版保持自然阅读方向。镜像版对每一页的全部视觉元素使用整页水平翻转，适用于背贴、反贴或用户现有KT板打印流程。镜像只是显示与打印变换，不生成第二份内容记录。

## 打印与PDF

打印根节点包含3张`210mm × 297mm`的A4页面，使用`@page { size: A4 portrait; margin: 0; }`与精确分页。浏览器打印按钮打开独立打印窗口，用户可选择实体打印机或“另存为PDF”。打印窗口不包含LCJ侧栏、按钮、编辑表单或其他后台内容。

## 权限与审计

查看和保存沿用店铺商品管理的登录权限。保存时服务器校验商品存在、证据图片属于该商品、数组数量与文字长度，并写入`store_product_audit_logs`，动作名为`handcard_updated`。手卡表只保存结构化文字和现有商品图片ID，不存放文件字节、不复制图片、不修改原商品、SKU、库存、推广或选品中心资料。
