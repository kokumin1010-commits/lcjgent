# 现金流分类净支出分析规格

## 目标

“カテゴリ別支出分析”改为“カテゴリ別純支出分析”。同一筛选范围内，每个分类必须按同一币种分别计算：

> 净支出 = 出金合计 − 入金合计

原始流水、金额、方向和分类均不修改；本功能只改变聚合口径和展示。

## 聚合规则

| 字段 | 公式 |
|---|---|
| 出金合计 | `SUM(amount WHERE type = 'expense')` |
| 入金合计 | `SUM(amount WHERE type = 'income')` |
| 净支出 | `出金合计 - 入金合计` |
| 件数 | 同分类、同币种的出金件数与入金件数之和 |
| 占比 | 正净支出 ÷ 同币种全部正净支出合计 |

JPY与CNY必须分别计算，禁止用参考汇率把一笔CNY退款抵扣JPY支出。参考JPY金额只用于跨分类排序，不改变原币种金额或占比。

## 边界语义

净支出大于0时显示为实际费用；等于0时显示“已全额冲抵”；小于0时显示“净回款”，金额保持负数并使用绿色提示。零或负净支出不进入“费用占比”的分母，其占比显示0%，防止退款分类把其他费用占比放大或产生负占比。

柱状图只按正净支出绘制宽度；零或负净支出不绘制误导性的正向费用柱。列表和表格必须同时显示净支出，并提供“出金合计 − 入金合计”的可核对明细。

## 示例

| 分类 | 币种 | 出金 | 入金 | 净支出 | 状态 |
|---|---|---:|---:|---:|---|
| 商品仕入 | JPY | 1,000,000 | 200,000 | 800,000 | 实际费用 |
| 口座間振替 | JPY | 20,000,000 | 20,000,000 | 0 | 已全额冲抵 |
| 返金调整 | JPY | 100,000 | 150,000 | -50,000 | 净回款 |

## 安全与兼容

服务端是唯一权威计算源。前端不重新推导净额，只展示服务端返回的出金、入金、净支出和占比。现有收入/支出列表、余额、现金流汇总、分类修改、工资保护和导入逻辑保持不变。生产验收不得修改真实流水。
