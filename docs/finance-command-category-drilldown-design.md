# 财务司令塔主要支出双币与下钻设计

## 范围

“最近30天主要支出”按 `asOf` 向前包含30个业务日期。每个类别继续显示数据库原币金额，同时显示 `JPY参考 = CNY原币金额 × 20.5`；JPY类别的原币与JPY参考相同，不重复造成误解。类别按JPY参考金额统一降序排列。

## 点击参数

点击类别时传递唯一筛选上下文：`entity`、`flowType=expense`、`category`、`currency`、`startDate`、`endDate`。财务主页面切换到现有入出金管理，并由同一个 `cashflow.getTotalSummary` 与 `cashflow.getReconciliation` 重建该类别总额及逐笔累计，禁止另建第二套计算逻辑。

## 权限

财务二次验证继续由现有路由保护。工资类别未解锁时，工资总额、笔数和JPY参考值完整显示，但逐笔个人工资合并成受保护汇总行；只有工资二次验证后才显示姓名或个人金额。类别下钻不降低现有权限。

## 可复核性

详情必须显示原币权威总额、逐笔累计、跨币种JPY参考以及“权威总额−逐笔累计=0”。司令塔传入的类别金额与现金流详情使用相同日期、法人、币种和类别筛选。
