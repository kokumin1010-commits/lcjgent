# 上場準備・業績司令塔 设计

## 目标

在 `finance-command` 页面为经营者提供“目标—实际—差额—必要速度—下一步行动”的单一视图。LCJ的决算期固定为7月31日。

## 公司计划目标

| 阶段 | 期间 | 公司计划利益目标 | 说明 |
|---|---|---:|---|
| N-2期上期 | 2026-08-01〜2027-01-31 | 1亿日元 | 6个月累计目标 |
| N-2期通期 | 2026-08-01〜2027-07-31 | 2亿日元 | 12个月累计目标 |
| N-1期通期 | 2027-08-01〜2028-07-31 | 5亿日元以上 | 上场准备最低目标 |
| 上场准备期上期 | 2028-08-01〜2029-01-31 | 5亿日元以上 | 半年内证明持续获利能力 |
| 最短上场 | 2029年中旬 | — | 以业绩、审计与内部控制均满足为前提 |

这些数字属于用户指定的公司计划，不是已实现业绩、审计结果或上市保证。

## 数据层级

1. **正式月次损益**：由财务人员按月份录入并选择草稿、月结或审计状态。上场目标完成率只使用月结／审计数据。
2. **现金收支参考**：由银行流水计算经营入金减经营出金，排除本社送金与账户间转账。只用于发现趋势，不称为会计利润。
3. **目标值**：公司计划常量，始终标注“计划”。

若正式月次损益尚未录入，页面必须显示“正式利润未登记”，不得用现金净额替代利润完成率。

## 月次损益字段

- 月份（YYYY-MM，7月决算）
- 売上高
- 粗利益
- 営業利益（上场目标的默认比较指标）
- 当期純利益（可选）
- 状态：草稿／月结／审计
- 备注、操作人、更新时间

所有金额为JPY。修改保留更新时间与操作人；不从现金流自动生成正式利润。

## 经营者指标

- 当前阶段与剩余月份
- 公司计划利益目标
- 正式累计营业利润
- 正式数据覆盖月数与最后月结月份
- 目标差额
- 剩余每月必要利润
- 按已月结平均速度预测的期末利润
- 完成率（只有正式月结／审计数据时显示）
- 现金经营净额参考（独立显示）
- 数据状态：正式／部分／未登记

## 行动建议

| 触发条件 | 行动 |
|---|---|
| 正式月次损益未登记 | 打开“月次损益更新” |
| 月结延迟超过上月 | 要求财务完成月结 |
| 预测低于目标 | 打开入出金明细，核对高额支出与收入不足 |
| 粗利率下降 | 要求品牌／商品别毛利分析 |
| 现金净流出 | 打开月别入出金与资金预测 |
| 银行余额过期 | 更新余额基准日 |

## 权限与安全

全部接口沿用财务二次验证。司令塔只读；月次损益更新为受财务权限保护的显式操作。计划值、正式业绩、现金参考必须使用不同标签和颜色。不得把预测值表述为已实现或保证上市。
