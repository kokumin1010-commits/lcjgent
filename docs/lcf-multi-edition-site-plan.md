# LCF 多届品牌官网规划

## 目标

LIVE COMMERCE FESTIVAL 官网从“2026第一届活动报名页”升级为可持续承载第二届、第三届及以后活动的品牌平台。品牌总入口长期稳定，年度活动页面独立归档，报名、登录、マイページ、ブース预约、Guidance和管理后台继续使用现有路径，不随品牌首页重构而改变。

> 品牌定位：企业、コマースライバー与平台在真实现场相遇，把内容、商品和销售结果连接起来的ライブコマース产业平台。

## URL与页面职责

| URL | 页面职责 | 长期策略 |
|---|---|---|
| `/` | LCF品牌总入口 | 展示最新状态、第一届成果、媒体报道、历届入口和下一届联系入口 |
| `/livecommercefestival` | 品牌总入口别名 | 与根域保持同一内容，兼容既有外链 |
| `/livecommercefestival/2026` | 第1届完整活动页 | 保留既有嘉宾、日程、企业、会场和历史资料 |
| `/livecommercefestival/2026/report` | 第1届開催レポート | 使用精选官方相册、真实成果和媒体链接形成永久档案 |
| `/livecommercefestival/{year}` | 未来年度详情页 | 每届独立发布，不覆盖历史年份 |
| `/lcf/*` | 登录、用户页、预约、Guidance和后台 | 运营系统保持不变，不纳入品牌展示重构 |

## 品牌首页结构

品牌首页采用“第一届成果证明 → LCF长期价值 → 历届档案 → 下一届行动”的叙事，而不是继续展示已经结束的第一届事前报名活动。

| 顺序 | 区块 | 核心内容 |
|---:|---|---|
| 1 | Hero | 真实会场主视觉；`LIVE COMMERCE MOVES PEOPLE.`；第1回盛況结束标记；第一届报告与次回案内两个CTA |
| 2 | Proven Impact | 750名以上ライバー、50社、15分钟193箱、DAY2全セミナー満席 |
| 3 | What LCF Creates | マッチング、商品体验、ライブ販売、知识共享、社交与表彰 |
| 4 | 2026 Highlight Mosaic | 会场规模、舞台、ブース互动、ライブ配信、アワード的非重复照片组合 |
| 5 | Media Coverage | 官方快报、PR TIMES、日刊スポーツ、スポーツ報知、デイリー、モデルプレス、Pop'n'Roll、LIVE TIMES外链 |
| 6 | Editions Archive | 第1回 `LCF 2026`档案卡；未来按年份自然追加 |
| 7 | Next Chapter | 不虚构日期，只显示`次回開催に向けて準備中`；为出展企业、ライバー、媒体分别提供联系入口 |
| 8 | Persistent Utility | `2026開催レポート`、`2026イベントページ`、`マイページ`三个稳定入口 |

## 第1届開催レポート结构

第1届报告使用官方已公开数字，不以生产后台签到计数替代对外统计。页面内容按事件体验展开：开幕与会场热度、企业与ライバー匹配、现场直播销售、DAY2研讨会、アフターパーティー与LIVE COMMERCE AWARD、媒体报道、完整精选画廊。

| 模块 | 照片目标 | 说明 |
|---|---:|---|
| 报告Hero | 1张 | 横向、大场景、LCF标识或人群热度明确 |
| 数据证明 | 2～4张 | 舞台、人群、企业ブース、ライブ販売 |
| DAY1 | 8～12张 | 入场、展位、互动、特别节目、直播销售 |
| アフターパーティー／AWARD | 6～10张 | 大合影、举杯、颁奖、获奖成果 |
| DAY2 | 8～12张 | 满席研讨会、观众、演讲、企业互动 |
| 精选画廊 | 36～50张 | 经过两轮筛选的单张原图，避免相邻重复 |

## 视觉系统

设计沿用LCF已经建立的黑、金品牌识别，但从旧式促销落地页升级为“日本现场文化杂志＋行业峰会档案”的编辑型设计。背景使用墨黑和暖白交替，金色只用于年份、数据和关键行动；照片使用大幅不对称排版、胶片式编号和细线框，不使用均匀卡片堆叠。

标题使用紧凑的无衬线黑体与宽字距英文组合；正文保持高可读日文。动效只用于照片淡入、数字区块和媒体卡片的轻微位移，控制在300毫秒内并尊重`prefers-reduced-motion`。移动端优先保持Hero文字对比、照片完整焦点和单手可触达CTA。

## 内容与合规边界

官网只使用用户提供相册中的公开照片及其正式原图，不抓取或复制新闻媒体图片。媒体区仅显示媒体名称、报道标题、日期和外链。不得虚构第二届日期、地点、出展者、赞助商、评价或报名人数；在新一届信息确定前统一使用`次回開催に向けて準備中`。

对外成果采用官方已发布数据：两天750名以上ライバー、50家企业、DAY1约500人、15分钟193箱、アフターパーティー约200人、DAY2全部研讨内容满席。[1][2][3]

## 技术结构

新增集中式年度数据模块，包含年份、状态、日期、地点、指标、外链、报告路径和精选图片。品牌首页及年度报告均消费该数据，未来新增第二届时只需增加一条edition记录和对应页面内容，不重写全站导航。

图片原图在筛选后上传至稳定CDN，不把大尺寸图片写入Git仓库。首屏只预加载1张Hero，其他图片使用`loading="lazy"`和明确宽高比，降低移动端首屏压力。既有业务路由和服务端接口不改动。
