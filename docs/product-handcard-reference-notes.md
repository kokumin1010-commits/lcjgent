## 普通版PDF观察

### 共通版式
- 共3页，均为A4纵向单页风格。
- 页眉左上为品牌名 `Dr.Alba`，右上为页码 `01/02/03`。
- 每页有明确的英文小节标签，例如 `DERMA PROGRAM No.1`、`DERMA PROGRAM No.2`、`SKIN PERFORMANCE / PATENTS`。
- 主标题为大号日文；副标题为较小一行，包含品类与容量。
- 页面主视觉采用“左文右图”或“上图下数据”的印刷海报布局，适合单页打印。

### 第1页
- 浅蓝背景。
- 右上产品图，左侧为标题、短说明。
- 中部为三列表格：`成分 / 主な働き / 肌への効果`。
- 底部深色总结框，总结No.1整体功效。

### 第2页
- 深蓝背景。
- 右上产品图，左侧为标题与说明。
- 中部延续三列表格，信息密度高于第1页。
- 底部浅色总结框，总结No.2整体功效。

### 第3页
- 浅底色。
- 上部为使用前后对比图，含 BEFORE / AFTER 标记。
- 中部为4个核心数字指标（百分比、小时等）。
- 下部为4个专利/证书缩略图及编号。

## 镜像版PDF观察
- 与普通版同为3页、同顺序、同内容层级。
- 每页整体做了左右镜像，文本与图片均为镜像状态。
- 适用于需要镜像打印/背投/KT板反贴等场景。
- 因此系统应提供：
  1. 普通版预览/打印
  2. 镜像版预览/打印
- 最好由同一个HTML/A4模板通过 `scaleX(-1)` 或镜像打印样式生成，而不是维护两套完全独立内容。

## 对LCJ商品手卡功能的直接要求
- 每个商品需要至少支持1页A4纵向打印。
- 当商品资料完整时，可扩展为多页手卡，而不是强制固定3页。
- 模板必须支持：品牌、商品名、副标题/规格、主图、卖点简介、成分/特点表、使用方法、价格、SKU/SPU、注意事项、证书/专利/试验图（若有）。
- 任何缺失字段必须明确显示“未登记/请补充”，不能自动编造。
- 应提供浏览器打印友好的A4尺寸CSS，以及PDF保存能力。
- 商品操作中应能从店铺商品列表直接进入手卡预览/编辑。
