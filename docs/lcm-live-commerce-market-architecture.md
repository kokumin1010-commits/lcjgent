# LCM｜ライブコマースマーケット 設計方針

## 目的

LCMは一般消費者向けECやTikTok Shopの代替ではなく、LCF参加企業、ライバー、事務所、販売事業者が商品を発見し、サンプル・卸商談へ進むためのB2B市場とする。注文・決済・佣金計算は初期範囲に含めず、TikTok Shop、Amazon、楽天、公式ECを販売先として接続する。

## 既存資産の再利用

| 既存資産 | LCMでの扱い |
|---|---|
| `festival_accounts` | LCM会員認証の唯一の基点。別パスワードを作らない |
| 企業・ライバー・一般参加申込 | 本人確認と初期プロフィール候補。申込原文や連絡先は公開しない |
| `brands` / `brand_products` | LCJ内部の既存ブランド・商品参照。LCM公開は明示承認後のみ |
| `brand_portals` / `brand_portal_products` | 既存商品入力・画像項目を参照するが、URLトークンをLCM公開編集権限として使わない |
| `sample_requests` | ライバー社内運用向けの既存申請として維持。LCM申請とは混在させない |
| 第1回出展企業カタログ | 公開済みの編集部アーカイブとしてLCM初期商品探索へ表示。卸・サンプル可とはみなさない |

## 権限

| 利用者 | 公開情報 | 会員限定卸条件 | サンプル・卸申請 | ブランド編集 | 運営審査 |
|---|---:|---:|---:|---:|---:|
| 未ログイン | 閲覧可 | 不可 | 不可 | 不可 | 不可 |
| LCFログイン済み・LCM未承認 | 閲覧可 | 不可 | 会員申請のみ | 不可 | 不可 |
| LCM承認会員 | 閲覧可 | 閲覧可 | 可 | 所有ブランドのみ | 不可 |
| ブランド所有者 | 閲覧可 | 自社分可 | 受領・処理可 | 所有ブランドのみ | 不可 |
| LCF管理者 | 全件 | 全件 | 全件 | 全件 | 可 |

メール、電話、住所、申込原文、内部メモ、卸条件は一般公開しない。配送先は対象申請の申請者、対象ブランド所有者、LCF管理者だけが参照できる。

## 公開状態

ブランドと商品は `draft → submitted → published` を基本とし、却下時は `rejected`、停止時は `suspended`、終了時は `archived` とする。公開ページは `published` だけを返し、企業による編集後は審査対象項目を再度 `submitted` とする。運営は却下理由を必須入力する。

## LCM会員状態

LCM会員は `pending → approved` または `rejected`、運用停止時は `suspended` とする。既存LCFアカウントを自動承認せず、利用規約、公開・取引目的、連絡同意を本人が確認して申請する。

## サンプル申請

`pending → approved / rejected → preparing → shipped → delivered → live_scheduled → completed` を正規経路とする。申請者は `pending` 中だけ取消可能。ブランドは承認、却下、発送情報登録、受取確認依頼を行い、運営は全状態を監督できる。同一商品への未完了申請は1会員1件までとし、月間上限を超えて承認できない。

## 卸商談

`requested → reviewing → accepted / declined → negotiating → completed / cancelled` とする。初期版は発注・決済を行わず、希望数量、用途、希望開始日、メッセージ、ブランド回答、進捗だけを保持する。卸価格には税込区分、最小発注数、送料、支払条件、価格有効期限を必須で関連付ける。

## 公開マーケット

公開URLは `/lcm`、ブランドは `/lcm/brands/:slug`、商品は `/lcm/products/:slug` とする。検索、カテゴリ、募集状態、販売先で絞り込み、公開プロフィールと公開商品だけをSEO対象とする。第1回カタログは「LCF 2026出展アーカイブ」と明示し、サンプル・卸取引が現在可能とは表示しない。

## 企業・運営画面

企業は `/lcm/manage` でブランド、商品、公開プレビュー、サンプル申請、卸商談を管理する。運営は `/lcm/admin` で会員審査、ブランド・商品審査、申請進捗、監査履歴を確認する。すべての更新は操作者、対象、変更前後、日時を監査ログへ保存する。

## 非目標

初期版ではLCM内の決済、注文確定、請求書発行、在庫引当、TikTok Shopへの自動ログイン、非公式スクレイピング、API未承認の自動同期を行わない。外部販売先へのリンクはHTTPSの許可済みホストだけを表示する。
