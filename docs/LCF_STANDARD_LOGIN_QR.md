# LCF標準ログインQRコード

今後、LCFログイン案内では`docs/assets/lcf-login-qr-standard.png`を標準原本として使用します。ユーザーが実機で読み取り可能であることを確認済みです。原本は再生成、切り抜き、色変更、角丸化、ロゴ追加または圧縮を行わず、そのまま使用します。

| 項目 | 値 |
|---|---|
| 形式 | PNG、RGB、ノンインターレース |
| サイズ | 450×450 px |
| SHA-256 | `c504ffeb85fb1048f0d750383d9e26b2feca79a5195bb82ea403c14df414ba32` |
| 利用目的 | LCFログインリンク案内 |
| 変更ルール | 原本のバイト列を変更しない |

原本の配布時は、このファイルを直接添付します。印刷物へ配置する場合も画像自体は加工せず、周囲の余白を保持します。
